# Автотесты для API Яндекс.Самокат

Проект содержит автотест для проверки сценария получения заказа по его трек-номеру.

## Установка
1. Откройте проект в VS Code.
2. Создайте виртуальное окружение через палитру команд (`Ctrl+Shift+P` -> `Python: Create Environment` -> `Venv`).
3. Установите библиотеку `requests`

## Запуск тестов
1. Откройте панель **Testing** (иконка колбы на левой панели VS Code).
2. Нажмите кнопку **Run All Tests** (треугольник вверху) или запустите тест отдельно, нажав на зеленую стрелку рядом с его названием.
