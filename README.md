# Яндекс Самокат — Финальный проект

## Описание проекта

Репозиторий содержит выполненные задания в рамках тестирования сервиса аренды самокатов «Яндекс Самокат». 

В проекте представлены:
* **Задание 1** — SQL-запрос для вывода логинов курьеров и количества их заказов в статусе «В доставке».
* **Задание 2** — SQL-запрос для вывода трек-номеров заказов и их статусов.
* **Задание 3** — Автотесты API на языке Python (проверка сценария получения заказа по его трек-номеру).

## Структура репозитория

| Директория | Содержимое | Выполняемое задание |
| :--- | :--- | :--- |
|  `task1_database/` | `task1_query.sql`, `task1_result.txt`, `task1_screenshot.png` | Логины курьеров и количество заказов в доставке |
| `task2_database/` | `task2_query.sql`, `task2_result.txt`, `task2_screenshot.png` | Все трекеры заказов и их статусы |
| `task3_vscode/` | Код автотестов (`test_order_track.py` и др.), `task3_screenshot.png`, `README.md` | Автотесты API (проверка получения заказа по треку) |
